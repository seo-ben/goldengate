# Golden Gate - Rénovation de Luxe & Travaux Haut de Gamme

Site web vitrine moderne et immersif pour **Golden Gate**, spécialiste en rénovation haut de gamme, staff, stuc marbre, peinture décorative et finitions architecturales de luxe.

## ✨ Fonctionnalités

- **Expérience Visuelle Immersive** : Vidéos d'arrière-plan, effets de verre (glassmorphism), typographies raffinées et transitions soignées.
- **Galerie & Portfolio Interactif** : Filtres par catégorie de projet, visionneuse plein écran HD, comparateur Avant / Après interactif.
- **Simulateur de Devis & Chatbot** : Estimation en direct et assistant interactif connecté pour orienter les clients.
- **Intégration WhatsApp Directe** : Prise de contact instantanée en un clic.
- **Optimisé SEO & Performance** : Balises Open Graph, métadonnées structurées, micro-animations réactives et architecture modulaire.
- **Déploiement Automatisé** : Configurations prêtes pour GitHub Actions (Pages), Vercel et Netlify.

## 🛠️ Stack Technique

- **Frontend** : React 19, Vite, Lucide Icons, Canvas Confetti
- **Styles** : Vanilla CSS moderne (Design System sur mesure, responsive design)
- **CI/CD** : GitHub Actions, Vercel, Netlify

## 🚀 Installation Locale

```bash
# Cloner le dépôt
git clone https://github.com/seo-ben/goldengate.git

# Accéder au dossier
cd goldengate

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

## 📦 Construction pour la Production

```bash
npm run build
```
